### 3. WikiJS Validation Agent

**Purpose**: Test connectivity, read existing content, and programmatically generate new documentation pages on a specified WikiJS instance. This agent ensures the reliable integration between the backend system and the WikiJS platform.

**Workflow**:
1. **Authentication**: Obtain an access token for secure API interaction with the WikiJS instance.
2. **Search (Read-Only)**: Query the wiki content to find pages or sections matching a specific keyword (`mode=search`).
3. **Read (Read-Only)**: Retrieve the full content of a specified page path, useful for auditing existing documentation (`mode=read`).
4. **Create (Write)**: Generate new documentation pages automatically based on provided context and prompts (`mode=create`).

**Configuration**:
```json
{
  "base_url": "http://localhost:8080", // Target WikiJS instance URL
  "token": "fake.jwt.token.for.anon.use",
  "mode": "read", // Default mode (read-only)
  "default_locale": "en"
}
```

**Use Cases**:
- **Connectivity Testing**: Verify the connection and accessibility of the WikiJS API.
- **Content Auditing**: Read the content of a specific page to verify its structure or state (`mode=read`).
- **Knowledge Discovery**: Search for existing information in the documentation via keywords (`mode=search`).
- **Automated Documentation Generation**: Create new documentation pages from contexts generated by other agents or systems (`mode=create`).
